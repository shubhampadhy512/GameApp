## 📖 About

**The Upside Down** is a 2D narrative-driven combat experience set in a mysterious world full of hidden dangers and secrets. The story is inspired by Seasons 1 and 2 of the *Stranger Things* series.

You begin with a story introduction, then explore the environment to find hidden locations that trigger encounters. Finding the right areas moves the story forward, and winning fights unlocks new content. The game has a dark, suspenseful atmosphere with a focus on mystery and discovery.

> **Disclaimer:** This is an unofficial fan project made for learning. It is not affiliated with or endorsed by Netflix or the creators of *Stranger Things*.

## 🔁 Core Gameplay Loop

```text
Story  →  Exploration  →  Combat  →  Unlocks
```

Defeating enemies rewards you with:

- 🧑‍🤝‍🧑 New playable characters
- 🗺️ New levels and areas to explore

## ✨ Features

- 📚 Story-driven progression with an intro and narrative events
- 🔎 Exploration where hidden locations trigger encounters
- ⚔️ 2D combat that rewards improving your skills
- 🔓 Unlockable characters and levels
- 🌑 Dark, suspenseful mystery atmosphere
- 📱 Built for Android

## 🛠️ Run the Project (for developers)

### Prerequisites

- [Unity Hub](https://unity.com/download)
- The Unity Editor version listed in `ProjectSettings/ProjectVersion.txt`
- Android Build Support module (to build for Android)
- A C# IDE such as Visual Studio, VS Code or JetBrains Rider

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/shubhampadhy512/GameApp.git

# 2. Open Unity Hub → Add → select the GameApp folder
# 3. Open the project with the matching Unity version
# 4. Open the main scene from the Assets folder and press Play ▶️
```

To build an APK: **File → Build Settings → Android → Build**.
